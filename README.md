# 杨公风水罗盘 · Android

一款参照传统**杨公盘**圈层绘制的 Android 风水罗盘：磁北定向、三层二十四山（正针/中针/缝针）、七十二龙、一百二十分金、内盘手动旋转叠针、石头摩擦音效、坐向双定位与「山向解读」实时理气弹窗。

> **免责声明**：罗盘测向功能真实可用（磁北）；应用内九运吉凶、卦理等内容仅为**传统民俗说法，没有科学依据**，仅供参考娱乐。现实选房请优先采光、通风、噪音、户型、消防、地质安全。

## ✨ 功能总览

### 盘面：13 层圈层（自外向内）

| # | 圈层 | 排布与用途 |
|---|------|-----------|
| 1 | 度数刻度环 | 360° 标尺，每 30° 标数，四正位红字北/东/南/西 |
| 2 | 六十四卦层 | 伏羲先天圆图，每卦 5.625°，复起子位顺时针 |
| 3 | 九星数字环 | 洛书数配八宫（1坎 8艮 3震 4巽 9离 2坤 7兑 6乾） |
| 4 | 二十八宿层 | 28 宿均分，角宿起辰巽（135°）逆时针 |
| 5 | 天盘缝针 24 山 | 顺时针错半位 7.5°，**纳水**用 |
| 6 | 人盘中针 24 山 | 逆时针错半位 7.5°，**消砂**用 |
| 7 | 地盘正针 24 山 | 红色大字，**格龙定向**基准层 |
| 8 | 七十二龙 | 每山三龙、正中龟甲空亡，六十甲子纳音五色 |
| 9 | 一百二十分金 | 每山五分金，细密刻度环 |
| 10 | 地支环 | 十二支每支 30°，子居北 |

### 交互

- **磁北定向**：旋转矢量传感器 + 低通滤波（老机型自动退回加速度+地磁融合）
- **叠针/纳针**：按住盘面拖动旋转内盘（外盘+天池一体），把海底线对齐磁针；**双击回正**；松手偏移 ≥150° 自动转正（红针恒指子）
- **石头摩擦音效**：音量随转速实时变化
- **圆形水平仪**：右下角悬浮，气泡居中变绿表示已水平
- **磁场偏弱提示**：自动提示画"8"字校准
- **天心十道**：贯穿盘心的固定红色十字线（四正字符处开让位缺口）

### 「山向解读」实时弹窗

打开左下角按钮，按当前坐向动态生成：

- **当前坐向**：坐X山 · 向Y山、俗称、九运吉凶（绿/黄/红着色）、方位、理气简评
- **七十二龙解读**：向线落哪条龙 / 龟甲空亡警告 / 纳音五行
- **一百二十分金解读**：落甲乙丙丁戊哪一分金、可用与否
- **正向/兼向判定**：距向山中心线 ≤3° 正向、3–6° 兼向、6–7.5° 近界缝
- **八卦详解**：方位 · 五行 · 洛书星 · 一卦三山 · 卦象人物 · 身体对应 · 生克喜忌 · 九运吉凶应用（当前宫 ▶ 置顶）
- **圈层详解**：13 层逐层说明（动态引用当前坐向的山名/支系/宫位/落龙）
- **二十四山对照表**：24 组坐向 + 九运吉凶，当前坐向 ▶ 高亮

### 底栏实时信息

「坐X山 · 向Y山」大字 + `度数 · 方位 · 吉凶 · 手动偏移` 小字，随手机转向实时刷新。

## 📱 安装

### 方式一：下载成品 APK

仓库内 [`yanggong-fengshui-luopan.apk`](yanggong-fengshui-luopan.apk)（v1.40，约 623KB），Android 5.0+ 手机直接安装，首次需允许"未知来源"。

### 方式二：自行构建

#### 依赖

| 工具 | 版本 | 说明 |
|------|------|------|
| JDK | 17 | `javac`（-source/-target 1.8） |
| Android build-tools | 34 | aapt2 / d8 / zipalign / apksigner |
| android.jar | platform-34 | 编译 classpath |
| PowerShell | 5.1+ | 构建脚本 |

默认 SDK 路径写在 `scripts/build.ps1` 头部：

- build-tools：`C:\android-build\android-14`
- android.jar：`C:\android-build\android-34\android.jar`

按你的 SDK 安装位置修改这两行即可。

#### 构建

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1
```

管线（无 Gradle，全手工调用）：

```
aapt2 compile → aapt2 link → javac → d8 → 追加 classes.dex → zipalign → apksigner(v1+v2)
```

产物：`build\luopan-v1.38.apk`（脚本自动打印 BUILD-OK 路径）。

#### 签名

仓库附带测试密钥 `scripts/release.keystore`：

- storepass / keypass：`luopan2026`
- alias：`luopan`

**对外发布前请务必换成自己的密钥**：

```powershell
keytool -genkeypair -keystore my-release.keystore -alias <别名> -keyalg RSA -keysize 2048 -validity 10950
```

并同步修改 `scripts/build.ps1` 里的 `--ks` / `--ks-key-alias` / 密码参数。

## 🧭 使用方法（叠针 / 纳针法）

1. **前置准备**：外盘天心十道竖线对准大门中轴线后锁死不动；手机放平（水平仪气泡居中）；远离金属；等磁针完全静止
2. **只转内盘**：按住盘面拖动，让红针（北端）对准海底线北端两颗红点，整条磁针与红线完全重合
3. **读数**：看天心十道竖线——靠近身体（屋内）= 坐山，朝外（门外）= 朝向；底栏同步显示
4. **解读**：点「山向解读」查看该坐向的九运理气、七十二龙、分金、正兼向与八卦详解

> 若松手时红针指在午端（叠反了），App 会自动转正：红针恒指子、黑针恒指午。
